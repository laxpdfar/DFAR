# Daily Field Activities Report (DFAR)

A fillable version of the LAWA Airport Police Daily Field Activities Report that runs in the browser.

**Open the app:** enable GitHub Pages for this repo (Settings → Pages → Source: *Deploy from a branch* → `main` / root). The app will then be at `https://<owner>.github.io/<repo>/`.

## What it does
- Activity log on two sheets (page 2 is the continuation sheet), with R/C time pairs
- Time fields are 24-hour dropdowns in 5-minute steps; the first R time follows the Watch (W1 0500, W2 1300, W3 2030)
- Source dropdown matching the Activity Totals categories
- Supervisor dropdown (W1–W3, alphabetical, selected watch first) in the Supervisor / Citation column
- Dictation (mic) on disposition boxes and Comments, in browsers that support it (Chrome, Edge, Safari)
- Officer signature pad (finger, stylus or mouse)
- Activity totals, officer/vehicle info, Total Miles = Mileage EOW − Mileage Out
- Daily Patrol Checkout List

## Saving and printing
- **Download Word (.docx):** a printable, landscape Word document of both sheets, including signatures
- **Print / PDF:** prints both sheets in landscape
- **Save file (.json) / Open file:** keep a report and reopen it later
- Drafts autosave in the browser on that device only. Nothing is sent to a server.

## Privacy note
Everything you type stays in your browser. Dictation in Chrome and Edge sends the audio to Google or Microsoft to turn it into text; use your device's own dictation if you'd rather avoid that.
